# СтАК — audit-spb

Статический сайт «СтильАктивКонсалт»: бухгалтерские услуги и консалтинг в Санкт-Петербурге.

Домен: [audit-spb.ru](https://audit-spb.ru/).

## Структура

- `index.html`, `index.css`, `site.js` — главная страница, оформление и интерактивные элементы.
- `images/optimized/` — адаптивные WebP, значок сайта и изображение для социальных сетей.
- `images/logowhite.png` — логотип, на который ссылается структурированная разметка.
- `robots.txt`, `sitemap.xml` — файлы для поисковых систем.
- Остальные HTML-файлы сохраняют старые адреса и перенаправляют на главную или нужный раздел.
- `scripts/` — проверка ссылок и сборка архива для размещения.

Сайт не требует Node.js, установки пакетов или сборки для просмотра. JavaScript используется для мобильного меню, плавных эффектов, подсветки разделов и сохранения согласия на статистику. Яндекс Карта загружается отложенно рядом с контактами. Контакты и основная навигация доступны и без JavaScript.

## Локальный просмотр

Из корня проекта, с установленным Python 3:

```sh
python3 -m http.server 8873 --bind 127.0.0.1
```

Открыть `http://127.0.0.1:8873/`. Остановить сервер: Ctrl+C.

## Проверка и подготовка к размещению

```sh
python3 scripts/check-site.py
python3 scripts/package-site.py
```

Проверка контролирует локальные ресурсы, якоря, повторяющиеся идентификаторы, атрибуты изображений, JSON-LD, sitemap и страницы перенаправлений. Сборка запускает проверку и создаёт ZIP сайта и манифест в `artifacts/`. Каталог создаётся автоматически и не хранится в Git.

Размещать на обычном хостинге нужно содержимое созданного ZIP с сохранением путей. Перед заменой сохранить текущую версию на хостинге. Скрипты подготовки не загружают файлы на сервер и не изменяют настройки домена.

## GitHub Pages

Основной адрес: [audit-spb.ru](https://audit-spb.ru/). Технический адрес [lexer85-hub.github.io/audit-spb](https://lexer85-hub.github.io/audit-spb/) перенаправляет на него. Для домена и `www` выпущен сертификат GitHub Pages, обязательный HTTPS включен.

Workflow `.github/workflows/pages.yml` проверяет и публикует сайт после изменений в ветке `main`. Его также можно запустить вручную через GitHub Actions. В настройках Pages источником публикации должен быть GitHub Actions.

Для локальной подготовки той же версии:

```sh
python3 scripts/build-pages.py --base-url https://lexer85-hub.github.io/audit-spb/
```

Результат появляется в `artifacts/pages/`. В публикацию входят только файлы сайта из манифеста и `.nojekyll`; исходники скриптов, документация и резервные архивы туда не попадают. Абсолютные ссылки в метаданных и sitemap заменяются на адрес Pages только в публикуемой копии. Исходники для `audit-spb.ru` сохраняют адрес действующего домена. Публикация на Pages не меняет DNS и файлы действующего хостинга.

## Особенности версии

В ноябре 2026 года универсальные библиотеки Nicepage и jQuery заменены собственными стилями и небольшим скриптом. Фотографии переведены в адаптивный WebP, нижние изображения загружаются отложенно. Сохранены фирменные изображения, услуги и контакты; добавлены поисковые метаданные и доступная навигация.

Сохранены шрифт Arial, полноширинный первый экран и фотографии. Основные разделы чередуют светлый и темный фон; блок контактов и обрамление карты используют нейтральный темно-серый фон в общей палитре сайта. В разделе «О нас» текст размещен слева, одна иллюстративная фотография работы с документами — справа; на телефоне она идет после текста. Фотография создана с помощью ИИ и сохранена в адаптивных WebP. Блок выровнен по ширине основного контейнера, карточки услуг имеют одинаковую высоту, отступы и размер основного текста согласованы. На узких экранах карточки и контакты с картой располагаются последовательно; ссылки услуг — в две колонки.

Дальнейшие изменения вносить в эти исходники: повторный экспорт из Nicepage перезапишет оптимизацию. Исходные резервные архивы, неиспользуемые файлы конструктора и локальные отчёты в репозиторий не входят.

В блоке контактов показан ориентировочный пеший маршрут от метро «Выборгская» до здания: 1,27 км, 16 минут по Яндекс Картам (проверено 12 ноября 2026 года). Время не включает путь внутри здания до офиса 234.

Фото Дворцового моста на первом экране улучшено с помощью обработки изображения: уточнены детали, свет и цвет. Используются отдельные WebP для узкого и широкого экрана и JPEG для предпросмотра ссылки. Предыдущие версии сохранены в репозитории.

Карточки «Проверка финансового состояния» и «Услуги методологии учета» содержат только текст; фотографии внутри карточек и за ними убраны, фон раздела — темный в общей палитре сайта. Яндекс Карта занимает всю правую ячейку контактов без дополнительных подписей сверху и снизу.

## Оформление услуг

Все четыре услуги оформлены по схеме «Когда нужна услуга / Что входит / Результат» с общей нумерацией 01–04. Номера совпадают с кнопками перехода. Фавикон использует белую подложку в SVG, чтобы знак был виден в темной теме браузера.

Добавлены плавное появление блоков, переходы по разделам, индикатор чтения, подсветка текущего пункта меню и кнопка «Наверх». Настройка уменьшения движения учитывается; при отключенном JavaScript содержимое остается доступным.

## Согласие на статистику

Баннер предлагает только «Да» и «Нет» для Яндекс Метрики и Google Analytics вместе. Решение сохраняется в localStorage (`stak.analytics-consent.v2`) на 180 дней, его можно изменить кнопкой внизу сайта. Если сохранение недоступно, выбор действует в текущем просмотре. До выбора согласие по умолчанию отсутствует.

Счетчики пока не подключены: владелец предоставит идентификаторы позднее. Сейчас нет запросов к аналитическим скриптам или передачи статистики. Для последующего подключения доступны `window.stakAnalyticsConsent.allowed` и событие `stak:analytics-consent` с `detail.allowed`; загрузчик должен учитывать согласие, его изменение и отзыв. Эти настройки относятся к аналитике; встроенная Яндекс Карта остается отдельным внешним виджетом.

Контакты разбиты на адрес, связь, часы и маршруты от метро. От «Площади Ленина» — ориентировочно 13 минут и 1,03 км пешком по Яндекс Картам (проверено 12 ноября 2026 года), от «Выборгской» — 16 минут и 1,27 км. Пункты шапки оформлены крупными текстовыми ссылками с подчеркиванием текущего раздела.

Кнопки используют острые углы и общий серый фон при наведении. Три элемента навигации шапки имеют одинаковые области нажатия и адаптируются под ширину экрана.

Сразу после первого экрана расположен светлый раздел «О нас», затем — темный раздел с кнопками услуг. Чередование фонов сохранено.

Карточка финансового состояния появляется слева, методология учета — справа. Положение и прозрачность зависят от прокрутки: у нижнего края экрана карточки сходятся, у верхнего расходятся. Эффект повторяется при движении в обе стороны; длинные карточки на телефоне остаются видимыми во время чтения. При уменьшении движения, печати и фокусе внутри карточки эффект отключен.

В шапке выбрана текстовая навигация: одинаковые области нажатия и тонкое подчеркивание при наведении и для текущего раздела.

Для текста на мосту выбран вариант «Легкий объем»: белый заголовок с двумя тонкими серыми слоями и мягкой тенью. Поясняющий текст получил мягкую тень; надписи остаются обычным HTML-текстом.

Шапка закреплена сверху и становится компактнее при прокрутке. Отступы якорных разделов учитывают ее высоту; при возвращении к началу исходный размер восстанавливается.
